What this is built on

No frameworks, no build step, and nothing fetched at run time — the browser loads the source directly. Three devDependencies exist for the optional lint, typecheck and end-to-end runs; none of them ships. What does ship that somebody else made:

  • Phosphor Icons MIT The sticker shapes. Vendored at a pinned revision, two weights, paint rewritten to this board’s paper and ink.
  • file‑analyser borrowed data Its catalogue of 1,359 file extensions, so a dropped .sldprt says “SolidWorks” and not “file”. The data, not the code around it.
  • Playfair, Fraunces, Geist OFL 1.1 The typefaces, subset to Latin and Latin Extended and otherwise untouched.

Full notices are in THIRD‑PARTY.md, and each licence sits beside the thing it covers. mbrd itself is GPL‑3.0‑or‑later.
