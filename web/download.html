Get mbrd for your computer or phone

The same board, on your own machine: real files, no browser limits, and it works with the network off.

Windows macOS Linux Android free, and the source is yours

Download mbrd
  • Windows: the .exe. One installer. It asks whether to install properly or unpack a portable copy you can carry on a stick.
  • macOS: the .dmg, Intel and Apple silicon in one file. New, less tested.
  • Linux: the .AppImage, which needs no install, or the .deb for Debian and Ubuntu, which opens boards on a double-click. New, less tested.
  • Android: the .apk, for Android 7 and later.
  1. The warning

    Your computer will say it does not recognise this app, and it is right. These builds are not code-signed — a signing certificate is a yearly fee to Microsoft or Apple, and mbrd has not paid one. Nothing about the app changes when it is signed; what changes is that your computer stops asking. Android asks too, because the app does not come from the Play Store.

  2. Windows

    SmartScreen shows a blue box saying “Windows protected your PC”. Press More info, then Run anyway.

  3. macOS

    macOS refuses the first run, because Apple has not checked the app. Open it once and close the warning. Then go to System Settings → Privacy & Security and press Open Anyway beside the message about mbrd. On macOS 15 and later the old right-click → Open trick no longer works, whatever the rest of the internet still says.

    If the Finder says instead that the app “is damaged and can’t be opened”, it is not damaged. Open Terminal and run:

    xattr -d com.apple.quarantine /Applications/mbrd.app

    Then open it normally.

  4. Linux

    Nothing complains, but an AppImage arrives without the executable bit. Run chmod +x mbrd-*.AppImage, then start it.

    The .deb installs with sudo apt install ./mbrd-*.deb. It tells you about a new version, and you install that one the same way.

  5. Android

    Android asks before it installs an app from outside the Play Store. When it asks, allow your browser or your file manager to install apps, then press Install.

  6. Or don’t

    None of this is required. The board in your browser is the same app and keeps your work on the same machine — see what it does with your things. The desktop build adds the parts a browser will not do: opening a .mbrd by double-clicking it, real files rather than a sandbox, and video work that runs on your own hardware instead of downloading a decoder.
