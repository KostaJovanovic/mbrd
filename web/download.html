Get mbrd for your computer

The same board, on your own machine: real files, no browser limits, and it works with the network off.

Windows macOS Linux free, and the source is yours

  • Download for Windows One installer. It asks whether to install properly or unpack a portable copy you can carry on a stick.
  • Download for macOS Intel and Apple silicon in one file.
  • Download for Linux An AppImage. Make it executable and run it — no install, no package manager.
  1. The warning

    Your computer will say it does not recognise this app, and it is right. These builds are not code-signed — a signing certificate is a yearly fee to Microsoft or Apple, and mbrd has not paid one. Nothing about the app changes when it is signed; what changes is that your computer stops asking.

  2. Windows

    SmartScreen shows a blue box saying “Windows protected your PC”. Press More info, then Run anyway.

  3. macOS

    The Finder says the app “is damaged and can’t be opened”. It is not damaged — that is the message macOS shows for an app it has no signature for. Open Terminal and run:

    xattr -d com.apple.quarantine /Applications/mbrd.app

    Then open it normally. On macOS 15 and later the old right-click → Open trick no longer works, whatever the rest of the internet still says. If you would rather not use Terminal: open the app once, let it be refused, then go to System Settings → Privacy & Security and press Open Anyway beside the message about mbrd.

  4. Linux

    Nothing complains, but an AppImage arrives without the executable bit. Run chmod +x mbrd-*.AppImage, then start it.

  5. Or don’t

    None of this is required. The board in your browser is the same app and keeps your work on the same machine — see what it does with your things. The desktop build adds the parts a browser will not do: opening a .mbrd by double-clicking it, real files rather than a sandbox, and video work that runs on your own hardware instead of downloading a decoder.
