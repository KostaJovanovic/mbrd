# Features, 2026-10-07

**Status: partly done, 2026-10-08.** Items 1 to 16 built; the designs for 17
and 18 approved on 2026-10-08 and being built in order. Already made the same day,
and not repeated here: the Linux wheel (v0.648), a whimsy change as one
Timeline step (v0.649), and Cyrillic in the app's own type (v0.650).

The maintainer picked these by multiple choice on 2026-10-07, then answered
follow-up questions on each. The answers are recorded with the item, because
they are what the build has to match. The order is the order of work: small and
settled first, the two design docs last.

## The list

1. **Cyrillic follow-ups.** The Serbian/Macedonian `lang` rule
   (`cyrillicLang()`, `canvas/note-model.ts`) on card names, the board title,
   fence names and the masthead too, not only notes. Piazzolla behind the font
   menu's Fraunces and Playfair entries, with boards that saved the old value
   strings mapped to the new ones so the picker still shows them selected.
2. **B1.** A test that fails on `Lorem`, `[INSERT` or similar placeholder copy
   in `web/index.html`.
3. **B2.** Spotify and YouTube titles and covers (`canvas/embed-meta.ts`)
   fetched on first play rather than on display, with `privacy.html`, the README
   and the architecture doc saying so. A "Check for updates" setting, on by
   default, on the desktop and Android; the Help menu's check still works when
   it is off.
4. **Keep cards below the title card.** Rearrange lays the cards out as if the
   title card were not an obstacle, centres the block under the title, and puts
   its top edge one grid step below the title's foot. Today it leaves a gap and
   a cone that narrows towards the top.
5. **Colour search in Find.** Typing "red" shows the cards with red in them.
   Basic names (red, orange, yellow, green, blue, purple, pink, brown, black,
   white, grey/gray), hex codes, and the modifiers dark, light, pastel, muted,
   warm and cool. Built on `dominantColors()` (`ui/pigments.ts`), cached per
   card.
6. **Rolling backups.** The last 10 saves of each board in `.autosave/` beside
   the boards on desktop and Android (like After Effects), a few snapshots in
   IndexedDB on the web, and "Earlier versions" on the shelf menu, which opens
   one as a copy.
7. **JSON Canvas** (Obsidian `.canvas`), import and export. Notes are text
   nodes, pictures file nodes, links link nodes, fences groups, connections
   edges. Export writes the `.canvas` and an assets folder.
8. **Alt+arrow spatial focus.** Alt+arrow moves focus to the nearest card in
   that direction. Plain arrows keep nudging. Tab between cards already exists.
9. **Starter layouts.** Empty structures (Moodboard, Character sheet, Project
   brief, Reference grid) made of titled fences, beside the Example board.
10. **Colourblind mode.** Safe interface accents and states (selection, the
    red dashed "unsure" line, warnings, tags) carried by pattern or icon as
    well as hue; a preset for each of deuteranopia, protanopia and tritanopia;
    a simulate-on-board filter; remapped note and swatch colours, with names on
    swatches.
11. **PureRef `.pur` import**, best effort. Position and scale first, then
    crop, flip, rotation and text notes where the file gives them up; anything
    unreadable lands as a plain grid of the images. No export.
12. **B3.** A CI smoke test (boot `web/` headless, load a board, fail on any
    console error). The deploy gated on CI was built and then dropped on
    2026-10-07: Cloudflare's git connection keeps deploying every push.
13. **Crown command.** After 1.0 versions read `1.<commits since 1.0>`, stamped
    by a `save.bat` verb, app and file names agreeing (1.5 is 1.5.0).
    `versionLabel()` tested.
14. **Android, sideload only.** `minifyEnabled`, the template's
    `ExampleInstrumentedTest.java` deleted, backup rules for `allowBackup`,
    "sideload only" on the download page.
15. **B7**, per `export-from-dom-2026-09-21.md`: export draws each card from its
    own DOM on Chromium, and the five common painters (picture, note, link,
    swatch, text) are fixed for Safari and Firefox.
16. **SVG export**, on top of B7.
17. **Pen.** Design doc first (`pen-2026-10-07.md`), approved before code. Decided: freehand pen,
    eraser and highlighter; follows the whimsy dial; a burst of strokes (no
    pause over about 2 s, close together) is one drawing card. No shapes, no
    text tool.
18. **Boards inside boards.** Design doc first (`boards-in-boards-2026-10-07.md`),
    approved before code. Decided:
    child boards live inside the parent `.mbrd`; a board card opens its child,
    with a breadcrumb back.
